ArtCraft をローカルの zip から起動

このページ自体には ArtCraft の本体は含まれていません。お手元の公式 Web 版 zip（例: vectorcraft-web-0.19.0.zip）を選ぶと、ブラウザの中でだけ解凍し、このブラウザのキャッシュに置いて起動します。zip の中身がサーバーに送られることはありません。特定のアプリ専用ではなく、index.html を含む静的サイトの zip なら汎用的に開けます。

期待する SHA-256（任意。入力すると照合します）:

zip ファイルを選んでください。

バージョンアップするときは、新しいバージョンの zip を選び直してください。古いキャッシュは消してから新しいものを置き直します。選んだ zip の SHA-256 は画面に表示するので、公式リリースのハッシュと見比べられます。

最新版チェック（公式 GitHub）

公式 GitHub（storytold）の Craft 系アプリを自動で探して最新版を調べ、Web版zipへの公式リンクを表示します。新しいアプリが増えても、公式に Web版zip付きで公開されれば一覧に自動で出ます。zip 本体は GitHub の配信仕様（CORS 許可ヘッダーなし）のためこのページの中へ直接は読み込めません。リンクからダウンロードして、上でファイルを選んで開いてください。
